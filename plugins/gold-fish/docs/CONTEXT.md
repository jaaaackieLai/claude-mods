# CONTEXT.md

`gold-fish` 的術語表。同一個東西永遠用這裡的名稱。
repo 共用的術語（mod、列、下層的列、吃掉列）見根目錄的 `CONTEXT.md`。

| 名稱 | 意思 |
|---|---|
| **gold-fish** | 這個 mod。它記住 session 裡的工作切換，讓使用者處理完支線後能回到主線 |
| **工作項** | 一件正在處理的工作，例如「修 typo-picker 的重複標出」。一個工作項只有標題和狀態（進行中或暫停） |
| **主線** | 分出支線的工作項。最底層的工作項也叫主線，即使它還沒有支線 |
| **支線** | 從主線分出來的工作項。支線也可以再分出支線 |
| **工作堆疊** | 依序排列的工作項。最底層是最早的主線，最上層是目前的工作項。每個 session 有自己的工作堆疊 |
| **金魚列** | `gold-fish` 畫的列，顯示工作堆疊。`><>` 標出目前的工作項，`∘` 標出暫停的工作項 |
| **合併項** | 金魚列放不下時，中間的工作項合併成「∘ N 項」。最底層的主線和目前的工作項一定顯示。金魚列窄到兩端都放不下時，只顯示目前的工作項 |
| **開支線** | Claude 判斷話題轉到支線時，把新的工作項放到工作堆疊最上層 |
| **收支線** | 把一個支線和它上面的工作項移出工作堆疊，並顯示回主線提醒。支線完成或放棄都算收支線 |
| **刪除工作項** | 只移除一個記錯的工作項，不顯示回主線提醒 |
| **回主線提醒** | 收支線以後，金魚列標出「↩ 回到主線」，輸入列放一句灰字建議。使用者送出下一則訊息後消失 |
